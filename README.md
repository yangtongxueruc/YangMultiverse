# YangMultiverse — 双宇宙微缩生态互动小游戏

基于 Three.js 构建的治愈系微缩 3D 交互页面，支持 **春日草原** 与 **大漠绿洲** 双宇宙独立切换（切换时自动保留各宇宙的动物、天气与灯光状态，仅在点击「重置场景」时恢复初始设定）：

- **春日草原**：小羊群生态（过木拱桥、贴贴/打架、跃同伴、雨天躲树下、怕羊圈、剪毛穿毛衣与黄金重生）、金渐层猫互动（屋顶晒太阳、礁石看鱼、扑蝴蝶洗脸、撸猫翻肚皮、拎后颈悬空等彩蛋）、河中游鱼与多天气切换。
- **大漠绿洲**：迷你羊驼（盘腿反刍、吐口水、沙浴打滚、绿洲浅滩踏水、剪毛换中东长袍/金边披风与头巾）、耳廓狐（蜷缩打盹、雷达听音、刨沙掘洞、原地高跳、坐着散热）、贝都因黑帐篷与篝火油灯、起伏沙丘、石子路浅滩及大漠四态天气。
- **视角与缩放**：右上角支持无损「放大」调节（`85%–220%`）与自由视角切换，放大后所有点选、拖拽、撸猫、画圈生羊与悬浮工具栏交互保持精准不受影响。

## 嵌入个人网站

发布到 GitHub Pages 后，可在个人网站中使用 `?pure=1` 隐藏顶部控制条，实现纯净全屏嵌入：

```html
<iframe
  src="https://<你的GitHub用户名>.github.io/YangMultiverse/?pure=1"
  style="width: 100%; height: 600px; border: 0; border-radius: 16px;"
  loading="lazy"
></iframe>
```

如需默认直接进入大漠绿洲或指定初始缩放倍率，可附加 `?world=desert`、`?zoom=1.25`（例如 `?pure=1&world=desert&zoom=1.2`）。
