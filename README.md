# YangMultiverse

YangMultiverse 是一款基于 Three.js 构建的纯前端 3D 粘土/羊毛毡风多元宇宙微缩生态互动箱庭（单文件 `index.html`，零后端依赖，开箱即用）。

## 包含的 6 个独立宇宙
1. **青青羊牧场**（Meadow）：小羊、金渐层守护猫、剪毛织毛衣与牧羊闭环
2. **绿洲羊驼谷**（Desert）：羊驼吐口水、沙尘暴与耳廓狐
3. **松果红枫林**（Forest）：胖松鼠抢松果、松果喷泉与小熊猫
4. **极地温泉湾**（Arctic）：小企鹅滑冰泡温泉、冰晶共鸣召唤极光与北极熊
5. **星砂珊瑚礁**（Coral）：寄居蟹排队换壳、漂流瓶、发光水母与海獭
6. **潜艇珊瑚谷**（Abyss）：
   - 4 种体型与条纹差异化小丑鱼 + 真实三段式打架（绕圈示威 → 咬嘴角力 → 侧身发抖求饶）
   - 4 套生态天气（蔚蓝日光海银鱼群、落日珊瑚海半沉落日与珊瑚产卵、洋流泡泡雨高速冲浪、深海荧光夜可点击发光水母与探照灯）
   - 大海龟顺风车、全缩壳与潜艇内部装水袋（4 款水袋扎口样式）→ 撞珊瑚戳破循环
   - 《海底总动员》伙伴彩蛋：蓝唐王鱼多莉（热心推水袋 & 读潜水镜）、粉红小章鱼珍珠（受惊喷紫墨云）、刺豚胖胖（膨胀成两倍大高浮刺球）、大白鲨布鲁斯与可点击卡通水雷（探头吓全场、委屈巡游、与小丑鱼三拍双向对手戏、甩尾帮推水袋）
   - 珊瑚隐藏彩蛋：连点 3 次珊瑚拱门点亮玫粉光门与鱼群轮流穿门绕圈、边缘珊瑚随机花园鳗躲猫猫、捉迷藏复古潜水镜

## 部署到 GitHub Pages
1. 解压本压缩包，将 `index.html`、`.nojekyll` 和 `README.md` 推送到 GitHub 仓库根目录（或 `docs/` 目录）。
2. 打开仓库 **Settings → Pages**，在 **Build and deployment** 中选择对应分支与根目录保存。
3. 等待约 1 分钟后即可通过 `https://<你的用户名>.github.io/<仓库名>/` 访问。
